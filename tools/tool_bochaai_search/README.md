# 博查搜索

调用博查 Web Search API，根据自然语言问题检索网页并返回 API 的 JSON 响应。

## 配置与调用

1. 在[博查开放平台](https://open.bochaai.com/)申请 API Key。
2. 从 MaxKB 工具商店添加工具，在启动参数 `apikey` 中填写密钥，然后启用工具。
3. 在应用或工作流中传入 `query`，例如 `MaxKB 最新版本功能`。

| 参数 | 用途 |
| --- | --- |
| `apikey` | 启动参数，博查 API Key |
| `query` | 必填输入，搜索问题或关键词 |

工具返回博查 API 的 JSON 对象；请求失败时抛出异常。原内置工具代码固定请求 8 条结果并包含摘要。
