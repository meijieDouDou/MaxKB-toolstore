# PostgreSQL 查询

连接 PostgreSQL 数据库执行 SQL，并把查询结果序列化为 JSON 字符串。

## 配置与调用

1. 从 MaxKB 工具商店添加工具，填写数据库连接启动参数，然后启用工具。
2. 在应用或工作流中传入 `query`，例如 `SELECT id, name FROM users LIMIT 10`。

| 参数 | 用途 |
| --- | --- |
| `host` | 启动参数，数据库主机 |
| `port` | 启动参数，端口；默认 5432 |
| `user` | 启动参数，数据库用户 |
| `password` | 启动参数，数据库密码 |
| `database` | 启动参数，数据库名 |
| `query` | 必填输入，要执行的 SQL |

工具返回 JSON 字符串，内容为查询结果行数组；连接或执行失败时抛出异常。建议使用只读数据库账号，并限制查询范围。
